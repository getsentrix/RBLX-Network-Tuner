The 6 Core Engineering Pillars

Engineered for raw competitive performance. No snake oil, no vague tweaks — just measurable, evidence-based systems engineering.

Adaptive Profile & Power Steering

Automatically distinguishes Wi-Fi vs. Ethernet. Bypasses wireless scanning on wired connections and temporarily disables Energy Efficient Ethernet (EEE) to eliminate physical interface sleep latency.

NetworkProfileDetector.cs

Hop-by-Hop Route Diagnostics

Non-locking parser tails live Roblox client logs to identify active game server IPs. Concurrently probes Gateway, ISP Edge, and Game Server hops to pinpoint the exact source of any latency spike.

RouteHopMonitor.cs

Bufferbloat & Contention Engine

Evaluates baseline idle RTT vs. loaded RTT during a 5MB burst with A+ to F grading, while an active watchdog monitors competing background hogs (OneDrive, Steam, Epic, Torrents).

BufferbloatDiagnosticModule.cs

Signal-Aware Wi-Fi Roaming Guard

Monitors Wi-Fi signal quality and RSSI in real time. If signal drops below 55% (-75 dBm), roaming scan suppression is automatically disengaged so your device seamlessly roams without disconnecting.

WifiOptimizationModule.cs

Audited QoS & UDP Fast Path

Applies DSCP 46 Expedited Forwarding to Roblox UDP packets with automated ISP degradation audits (auto-reverting if loss >15%), paired with Winsock AFD 1500-byte datagram buffer thresholds.

Frequently Asked Questions

Answers to Technical Questions

Clear, honest information about safety, antivirus behavior, and system mechanics.

Why did an antivirus engine flag the setup file on VirusTotal?

When scanning newly released installers on VirusTotal, 1–2 automated engines (such as McAfee Scanner with a rule like Ti!62A3A5E62541) may flag it. The "Ti!" prefix stands for Threat Intelligence—an automated cloud AI heuristic rule rather than an actual virus detection. Because the installer is a newly released, unsigned executable that embeds and extracts another executable (the tuner engine) into Program Files, heuristic scanners flag it as a generic dropper. The entire repository is 100% open source C# without obfuscation. If you prefer zero installation, simply download the portable RobloxNetworkTuner.exe directly.

Can I get banned from Roblox for using this?

No. Roblox Network Tuner operates 100% outside of the Roblox client process. It modifies standard Windows OS socket parameters, kernel multimedia timer periods, and Wi-Fi radio streaming modes. It performs zero memory injection, zero DLL hooking, zero binary patching, and zero game tampering. It is completely compliant with Roblox Terms of Service.

Are changes permanent or will they harm my PC?

All changes are 100% reversible. Before modifying any parameter, the initial state of your system is recorded to an atomic JSON file (tuner_state.json). As soon as you exit the tuner or close Roblox, every single setting is symmetrically restored back to stock Windows defaults. If your computer crashes or loses power, the crash recovery watchdog detects the file on next launch and automatically restores your original settings.

Does this help if I am already on a wired Ethernet connection?

Yes. The Adaptive Profile & Power Steering module recognizes your connection medium. While Wi-Fi users benefit from roaming-safe scan freezing, Ethernet users benefit from 0.50ms kernel thread timer resolution, Winsock AFD UDP datagram threshold tuning, TCP delayed ACK suppression, and Energy Efficient Ethernet (EEE) sleep latency prevention.
